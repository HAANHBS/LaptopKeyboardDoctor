# Release Notes

## Fixes and UX improvements

This update focuses on making keyboard diagnostics more reliable and easier to read during testing.

### Highlights
- Added missing keys on the keyboard map: Home, End, Page Up, Page Down, and Insert.
- Fixed tab navigation issues when using Home/End/Page Up/Page Down while monitoring a diagnostic tab.
- Improved the event log layout to prioritize the fields most useful for fault analysis.
- Reduced mouse/touchpad UI lag while preserving the core detection logic.
- Updated the product title and app icon for better readability and easier identification in the taskbar.

### Why this matters
These changes keep the tool aligned with its real purpose: detecting actual keyboard and touchpad faults quickly and clearly, without distracting UI behavior.

### Compatibility
- Windows 10/11
- Portable single-file EXE build
- No extra runtime dependencies required

### Notes
- The app remains focused on diagnosis and evidence collection.
- Diagnostic information is still exported as plain text and CSV for later review.
